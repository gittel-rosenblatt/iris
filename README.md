# Iris

> A web application designed to empower visually impaired individuals to fill out online PDF forms independently and seamlessly.

## Overview

My app is called Iris, after the part of the eye responsible for controlling the amount of light that enters the eye, as well as the flower and the Greek goddess. Iris is an accessibility-focused web application built for the Congressional App Challenge. It bridges the gap between complex digital PDF forms and visual accessibility needs.

## Our Mission

Iris is dedicated to making digital forms accessible to everyone and breaking down barriers to online accessibility. We believe that navigating the internet should be equitable, stress-free, and seamless for everyone. By transforming complex digital paperwork into clean, accessible user experiences, Iris empowers visually impaired individuals to navigate essential online spaces with absolute independence and confidence.

## Why I built Iris

My father has Retinitis Pigmentosa, which is a degenerative genetic eye disease that causes loss of vision over time. There is no cure and no real cause. I was inspired to make Iris because I know he struggles immensely with filling out PDF forms online. Iris is a website that helps visually impaired people fill out forms without the struggle.

## How It Works

1. **Profile Setup:** A user makes an account, then has the option to add certain information (e.g., full name, address, etc.) to their profile.

2. **Form Extraction:** When a PDF form is uploaded, Iris utilizes the Gemini API to parse and extract form fields, questions, and required inputs.

3. **Accessible Interface:** Questions are converted into a distraction-free, single-field-at-a-time interface featuring large, clear typography.

4. **Preview & Export:** Stored profile information automatically pre-fills matching fields. Once reviewed, the final document is exported as a completed, downloadable form.

## Technical Features & Accessibility

- **Built With:** Python, Flask, Jinja2, SQL, HTML5, CSS3, Gemini API
- **Accessibility Compliance:** Iris exceeds the WCAG AAA Standards with full support for up to 200% zoom without breaking layout responsiveness, as well as text-to-speech and voice-to-text.
- **Future Roadmap:** In future versions, Iris will have customizable font color and size.
